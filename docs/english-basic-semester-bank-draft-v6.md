### Read the text and answer Questions 111–115.

*A group of students decided to improve the way their college shared information about clubs and events. Previously, announcements were placed on several noticeboards, so students sometimes missed changes or received outdated details. The group interviewed classmates and discovered that most students preferred one regularly updated online page. They prepared a simple layout with separate sections for events, contact details and sign-up instructions. Before publishing it, they asked a teacher to check the information and tested the page on both phones and computers. The new page did not replace personal conversations with club organisers, but it made basic information easier to find.*

**111.** What problem did students identify?
- A. There were too few clubs in the college.
- B. Students could not use computers.
- C. Teachers refused to organise events.
- D. Information was spread across noticeboards and could become outdated.

**112.** What did the group learn from interviewing classmates?
- A. Most students preferred one updated online page.
- B. Students wanted announcements only on paper.
- C. Nobody was interested in college events.
- D. Students wanted to remove all contact details.

**113.** What did the group do before publishing the page?
- A. Cancelled the college clubs.
- B. Asked a teacher to check the information and tested the page.
- C. Replaced every organiser with a student.
- D. Printed the page as a textbook.

**114.** Which statement is true according to the text?
- A. The online page replaced all conversations.
- B. The page was designed only for computers.
- C. The page made basic information easier to find.
- D. The students stopped updating event details.

**115.** What is the main purpose of the text?
- A. To explain how students improved access to college event information.
- B. To compare different computer brands.
- C. To give instructions for organising a sports competition.
- D. To describe the history of the college building.

## Teacher key and rationale

| No. | Key | Rationale |
|---:|:---:|---|
| 101 | C | “Neither explanation” is singular, so it takes “was”. |
| 102 | A | “As soon as” introduces the time when the document should be sent. |
| 103 | B | In reported speech after “asked”, past perfect marks an action completed before the asking. |
| 104 | D | “Allow someone to do something” takes the infinitive with “to”. |
| 105 | B | “Clear” fits the result that nobody needed extra help. |
| 106 | C | “For” introduces a duration. |
| 107 | C | “Traffic” is uncountable and takes “less” with singular “is”. |
| 108 | A | First conditional with a passive result: “will be held”. |
| 109 | B | The fixed phrase is “responsible for”. |
| 110 | C | “Keep in touch” means maintain contact. |
| 111 | D | The text says announcements were on several noticeboards and details could be outdated. |
| 112 | A | The interviews showed that most students preferred one updated online page. |
| 113 | B | They requested a teacher's check and tested the page on phones and computers. |
| 114 | C | The final sentence says basic information became easier to find. |
| 115 | A | The passage describes a student project to improve access to event information. |
| 116 | C | Future perfect describes completion before a specified future time. |
| 117 | B | After modal “should”, use the base form “review”. |
| 118 | B | This reply politely accepts the request and offers to send the timetable. |
| 119 | B | “Outdated” means old or no longer current. |
| 120 | C | “In order to” introduces the purpose of testing the page. |
