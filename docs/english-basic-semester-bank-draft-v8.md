### Read the text and answer Questions 151–155.

*When a city transport operator introduced contactless payment, passengers could pay by tapping a bank card or a mobile device on the reader. The change reduced the need to buy paper tickets before boarding, but the operator reminded passengers to use the same card or device when entering and leaving the system. A passenger who changes payment methods during one journey may be charged incorrectly. Information posters were placed at major stations, and staff members were available during the first weeks to answer questions. The operator also kept a cash option at selected ticket offices for people who could not use digital payment.*

- A. Free journeys for every passenger

- D. A different timetable

**152.** What should passengers use consistently during one journey?

## Teacher key and rationale

| No. | Key | Rationale |

| 141 | B | The indirect question uses statement word order and singular “notebook”. |
| 142 | C | Past perfect continuous describes an action continuing up to another past event. |
| 143 | D | “Advise someone to do something” takes the infinitive with “to”. |
| 144 | D | “Information” is uncountable; “some” is suitable in an affirmative sentence. |
| 145 | A | “During the whole journey” is the correct time expression. |
| 146 | B | “Where” introduces a relative clause referring to a place. |
| 147 | A | Present perfect with “never” describes life experience. |
| 148 | C | In a first conditional instruction, the if-clause uses present simple. |
| 149 | B | “Too small” means smaller than needed. |
| 150 | C | A complaint expresses dissatisfaction with a product or service. |
| 151 | B | The first sentence identifies contactless payment as the new service. |
| 152 | A | Passengers are told to use the same card or device at entry and exit. |
| 153 | C | The text warns that changing payment methods may cause an incorrect charge. |
| 154 | D | Staff were available to answer questions during the introduction period. |
| 155 | B | Cash remained available for passengers unable to use digital payment. |
| 156 | C | Past perfect shows the train left before the passengers reached the platform. |
| 157 | A | The passive description “was damaged” explains the reason for the refund request. |
| 158 | D | This is a polite request using “could” and “please”. |
| 159 | A | “Selected” means chosen from a larger group. |
