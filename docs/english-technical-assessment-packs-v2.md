Эти комплекты дополняют, а не заменяют материалы из `english-new-assessment-content-v1.md`. Все задания новые относительно пилотного комплекта v1. До загрузки в рабочий банк требуется автоматическая и ручная сверка с полным содержимым существующих лекций, тестов и банков.

## Комплект B — Control Systems, PLC and Instrumentation (20 заданий)

1. A PLC is mainly used to:

   A) store mechanical spare parts
   B) control industrial processes according to a program
   C) measure only room temperature
   D) replace every electrical motor
2. In a control loop, the setpoint is:

   A) the measured error only
   B) the maximum cable length
   C) the desired value of a process variable
   D) the power supply rating
3. A thermocouple produces a voltage related to:

   A) fluid colour
   B) shaft diameter
   C) air humidity only
   D) temperature difference
4. An analogue signal can represent:

   A) a continuous range of values
   B) only ON and OFF states
   C) letters in a file name
   D) a fixed mechanical dimension only
5. A limit switch is commonly used to detect:

   A) the chemical composition of oil
   B) whether a moving part has reached a defined position
   C) the age of a machine
   D) the operator's identity
6. In a feedback system, the controller compares the measured value with the:

   A) machine serial number
   B) delivery date
   C) setpoint
   D) tool storage location
7. Match each instrument to the quantity it measures: 1) pressure gauge 2) tachometer 3) flow meter 4) multimeter.
   A) rotational speed
   B) electrical quantities
   C) fluid pressure
   D) flow rate

8. A proximity sensor detects an object:

   A) only after the object is cut
   B) by weighing it
   C) only when it is transparent
   D) without necessarily making physical contact
9. The alarm activates ___ the pressure exceeds the limit.

   A) when
   B) unless of
   C) despite
   D) whereas to
10. Choose the correct technical statement:

   A) The actuator sends a signal to the controller's past.
   B) The controller sends a signal to the actuator.
   C) The controller are send signal actuator.
   D) A signal sending the controller by actuator.
11. Put the basic closed-loop sequence in order:
    A) compare with setpoint
    B) measure the process variable
    C) adjust the control output
    D) detect the resulting process response
    Choose: A) B–A–C–D  B) C–D–A–B  C) A–B–D–C  D) D–C–B–A

12. “The valve failed to open” means that the valve:

   A) opened too quickly
   B) was removed from the system
   C) did not open as required
   D) measured the flow rate
13. Which description best fits an emergency stop circuit?

   A) It increases production speed during normal operation.
   B) It stores the machine's operating manual.
   C) It calibrates measuring instruments.
   D) It is intended to bring hazardous motion to a safe stop.
14. Select the correct reported instruction: The engineer said, “Check the sensor cable.”

   A) The engineer told us to check the sensor cable.
   B) The engineer said us check the sensor cable.
   C) The engineer told that check the sensor cable.
   D) The engineer says us checked the sensor cable.
15. A sensor gives unstable readings. Which is the most appropriate first action?

   A) Increase the machine speed immediately.
   B) Check the connections and the sensor installation.
   C) Remove all protective covers.
   D) Ignore the readings and continue production.
16. Read the log: “At 10:05 the tank level was 62%. At 10:20 it was 48%. The pump command remained ON.” What happened to the indicated level?

   A) It increased by 14 percentage points.
   B) It did not change.
   C) It decreased by 14 percentage points.
   D) It decreased by 48 percentage points.
17. Complete the sentence: “The pressure transmitter ___ a 4–20 mA signal to the controller.”

   A) send
   B) sending
   C) have send
   D) sends
18. Which document normally describes terminal connections and wiring routes?

   A) wiring diagram
   B) staff holiday schedule
   C) purchase receipt for office furniture
   D) product advertisement
19. “Intermittent fault” describes a fault that:

   A) is permanently visible
   B) occurs occasionally and is not continuously present
   C) has already been repaired and verified
   D) affects every machine in the factory
20. Choose the clearest maintenance note:

   A) “It was weird and then it got better.”
   B) “The thing did something.”
   C) “Input signal fluctuated between 8 and 15 mA during the test; cable connector was reseated.”
   D) “Machine probably bad.”

## Комплект C — Pneumatics, Hydraulics, Quality and Technical Documentation (20 заданий)

1. A pneumatic system uses:

   A) molten metal
   B) optical fibres only
   C) compressed air
   D) vacuum-packed solids only
2. A hydraulic system transmits power using:

   A) dry sand
   B) radio waves
   C) uncompressed air only
   D) pressurised liquid
3. The main function of a filter in a fluid power system is to:

   A) remove contaminants from the fluid
   B) increase the pipe length
   C) change the fluid into a solid
   D) measure the operator's reaction time
4. A pressure relief valve helps to:

   A) increase contamination
   B) limit system pressure to a safe value
   C) reverse the direction of every motor
   D) record production costs
5. A cylinder converts fluid power into:

   A) a written report
   B) electrical insulation
   C) linear mechanical motion
   D) a temperature reading only
6. “Leakage” in a hydraulic line means:

   A) pressure is measured correctly
   B) the filter has been replaced
   C) the pump is switched off by schedule
   D) fluid escapes from the system
7. Match the document with its purpose: 1) user manual 2) inspection report 3) bill of materials 4) maintenance schedule.
   A) lists components and quantities
   B) gives planned service dates/tasks
   C) records inspection findings
   D) explains operation and use

8. A calibration certificate provides evidence that an instrument:

   A) has been compared with reference standards under stated conditions
   B) is guaranteed never to fail
   C) does not require maintenance
   D) can measure every physical quantity
9. A batch number is used to:

   A) set the machine's cutting speed
   B) identify a production batch for traceability
   C) calculate an employee's working hours
   D) select the colour of a warning lamp
10. Choose the correct sentence:

   A) The samples was inspected before release.
   B) The samples inspected before release yesterday is.
   C) The samples were inspected before release.
   D) The samples were inspect before release.
11. The measured value is 24.8 mm and the nominal value is 25.0 mm. The deviation is:

   A) +0.2 mm
   B) −2.0 mm
   C) +2.0 mm
   D) −0.2 mm
12. A checklist is useful because it:

   A) helps ensure that required steps are not missed
   B) replaces all technical training
   C) removes the need for inspection
   D) automatically repairs equipment
13. “Do not exceed the rated load” means:

   A) the load should always be doubled
   B) the specified maximum load must not be exceeded
   C) the machine must run without a load
   D) the load is not important
14. Select the best connector: “The seal was damaged; ___, oil escaped from the joint.”

   A) in contrast
   B) for example
   C) as a result
   D) similarly
15. A root-cause investigation aims to identify:

   A) the person who speaks the loudest
   B) the colour of the machine
   C) the next public holiday
   D) the underlying reason why a problem occurred
16. Read the inspection note: “Three of twenty parts had burrs on the edge. The remaining seventeen met the visual acceptance criteria.” How many parts met the visual criteria?
    A) 3
    B) 17
    C) 20
    D) 23

17. Which phrase is most appropriate for a formal technical report?

   A) “The test results indicate a pressure drop across the filter.”
   B) “The filter is acting funny.”
   C) “We reckon something is wrong.”
   D) “The pressure did a strange thing.”
18. A revision number on a drawing helps users identify:

   A) the weight of the finished product
   B) which version of the drawing is current
   C) the operator's shift
   D) the machine's electricity tariff
19. Put the document-control actions in a sensible order:
    A) approve the revised drawing
    B) identify the required change
    C) issue the new revision
    D) review the proposed change
    Choose: A) B–D–A–C  B) C–A–D–B  C) D–C–B–A  D) A–B–C–D

20. “The equipment must be depressurised before the hose is disconnected.” What must happen first?

   A) the hose must be pulled off
   B) the pump must be accelerated
   C) pressure must be released safely
   D) the coupling must be heated

## Проверка качества и дальнейшее применение

- Объём дополнения: 40 заданий (B и C), всего с комплектом A из v1 — 60 новых технических заданий.
- Комплекты B и C проверены на буквальные повторы между собой и с комплектом A: одинаковых формулировок заданий не использовано.
- Тематические области распределены по отдельным контекстам: автоматическое управление и измерительные приборы; пневматика/гидравлика, качество, прослеживаемость и документация.
- В комплектах намеренно есть задания на чтение техзаписей, грамматику в профессиональном контексте, соответствия и последовательности.
- Для будущей загрузки правильные ответы должны быть вынесены из клиентского файла в серверный ключ. Приведённые здесь ключи предназначены для реализации, а не для публикации студентам.
- Перед включением в рабочий портал выполнить машинное сравнение со всеми 73 вопросами технического контента и вопросами Basic, а затем экспертную проверку соответствия уровню курса.
- Эти комплекты не объявляются готовыми 40-вопросными экзаменами и не заменяют существующие контрольные. Это расширение банка, из которого после утверждения спецификации можно собирать разные варианты.
