# Technical English — Course 3, Semester 1 — Lessons 9–12
## Manufacturing workflow, measurement, technical language and specification reading

**Status:** original draft lessons for the provisional five-year course map; not imported into the portal and not approved as official programme content.  
**Level:** B1–B1+ ESP.  
**Professional groups:** technologists, programmers, electricians and machine-tool operators.  
**Audio:** original Spotlight-style listening scripts are included as text for recording. No MP3 files or audio player are supplied.  
**Scope:** classroom English for reading and discussing controlled technical information. These materials are not manufacturing instructions, aircraft maintenance data or authority to operate equipment.

## Block outcomes

By the end of Lessons 9–12, students should be able to:
- describe a simplified manufacturing workflow and identify the purpose of a process sheet;
- recognise common dimension, unit and measurement vocabulary;
- distinguish nominal size, measured value, tolerance and unit;
- decode common technical abbreviations and symbols in context;
- read a simplified specification table and locate relevant information;
- communicate a discrepancy clearly without changing a technical requirement;
- connect the four professional strands through shared drawings, records and revisions.

# Lesson 9. Manufacturing Workflow and Process Sheets

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. describe the main stages of a simplified manufacturing workflow;
2. understand vocabulary for a process, operation, sequence, instruction and record;
3. identify the purpose and typical sections of a process sheet;
4. use sequence markers and the passive voice to describe operations;
5. listen for the sequence of steps and the documents used;
6. explain how different specialists use the same controlled information.

## 1. Lead-in

Discuss:
- Why is a product not usually made in one step?
- What information does a worker need before starting an operation?
- What can happen if two departments use different drawing revisions?
- Which records can help a team understand what happened during production?

A simplified workflow:

**Requirement and drawing → process planning → material and component preparation → manufacturing operations → in-process checks → final documentation and review**

The actual workflow depends on the product, organisation, applicable standards and approved procedures.

## 2. Vocabulary

| English | Russian | Example |
|---|---|---|
| workflow | рабочий процесс | The workflow contains several stages. |
| manufacturing process | производственный процесс | The manufacturing process is planned in advance. |
| process sheet | технологическая карта / операционная карта (по контексту) | The process sheet describes the planned sequence. |
| operation | операция | Each operation has a defined purpose. |
| sequence | последовательность | Follow the approved sequence. |
| work instruction | рабочая инструкция | The work instruction explains an authorised task. |
| workpiece | заготовка / обрабатываемая деталь | The workpiece is identified before the operation. |
| setup | наладка / установка (по контексту) | Setup information is recorded by authorised staff. |
| inspection | контроль / проверка | The inspection result is documented. |
| record | запись / документ учёта | The record includes the date and identification. |
| revision | редакция документа | Check the current revision. |
| traceability | прослеживаемость | Traceability links a part to its records. |
| approval | утверждение / согласование | The document requires approval. |
| non-conformity | несоответствие | A non-conformity must be reported. |
| responsible person | ответственное лицо | The responsible person reviews the record. |

## 3. Reading: what does a process sheet do?

Read:

“A process sheet is a controlled document used to describe planned manufacturing operations. Depending on the organisation and the product, it may identify the part, drawing number, revision, material, operation sequence, equipment category, inspection points and records to be completed. It helps different people understand what information applies to a particular part and stage of work.

A process sheet does not replace the drawing, specification or detailed work instruction. If information appears inconsistent, a student or operator should not guess which value is correct. The discrepancy must be referred to the responsible instructor or authorised person. Document revision is important because an old version may no longer represent the approved requirements.”

### First reading — gist

Choose the best summary.

A) A process sheet organises controlled information about planned manufacturing operations.  
B) A process sheet gives permission to change a design.  
C) A process sheet replaces every drawing and specification.

### Second reading — details

1. Name four types of information that may appear on a process sheet.
2. Which documents does a process sheet not replace?
3. What should a person do if two values appear inconsistent?
4. Why is the revision important?
5. Find one sentence that describes the purpose of the document.
6. What is the relationship between traceability and records?

### Practice 1. Match

1. revision  
2. workpiece  
3. inspection point  
4. traceability  
5. non-conformity

a) a feature or stage where a check is planned  
b) a difference from a stated requirement  
c) the item being processed  
d) the identification of a document version  
e) the ability to link an item with relevant history and records

## 4. Language focus: sequence and passive voice

Useful sequence markers:
- **initially / first** — the first stage;
- **after that / next** — the following stage;
- **during** — an action within a stage;
- **before / after** — time relationship;
- **finally** — the last stage.

Passive forms in process descriptions:
- The material **is identified**.
- The operation **is recorded**.
- The result **is checked**.
- The document **was revised** last month.

### Practice 2. Put the stages in a logical order

a) The result is recorded.  
b) The part and drawing revision are identified.  
c) The planned operation is completed by authorised personnel.  
d) The required check is carried out according to the approved procedure.

Then write four sentences using *first, next, after that, finally*.

### Practice 3. Choose the correct word

1. Check the drawing number and its (revision / weather).
2. The (workpiece / passenger) is identified before processing.
3. A result that does not meet a requirement may be recorded as a (non-conformity / timetable).
4. (Traceability / Decoration) connects an item with its records.

## 5. Listening: a process sheet briefing

**Before you listen**

Key words: *part number, revision, operation, inspection point, record, discrepancy*. Predict what information a student should check before describing a manufacturing sequence.

**First listening — gist**

What is the instructor explaining?

A) How to read a simplified process sheet.  
B) How to book a flight.  
C) How to prepare a meal.

**Second listening — details**

1. What should be checked first?
   A) part identification and drawing revision  
   B) the colour of the folder  
   C) the student's favourite tool
2. What does the process sheet show?
   A) a planned sequence of operations  
   B) private information about staff  
   C) a holiday schedule
3. What should happen if a discrepancy is found?
   A) report it to the responsible person  
   B) choose a value independently  
   C) hide the record
4. Why are records kept?
   A) to support traceability  
   B) to replace all technical requirements  
   C) to avoid communication

**Recording script — reveal after listening**

**Instructor:** Before you describe the workflow, look at the document identification.

**Student:** The part number and drawing revision?

**Instructor:** Correct. Then identify the operation sequence and any inspection points shown on this training example.

**Student:** Should I add a step if I think one is missing?

**Instructor:** No. This is a controlled document. Do not invent or change an operation. If something appears inconsistent, record the question and refer it to the responsible person.

**Student:** And the completed record helps us trace the work?

**Instructor:** Yes. It connects the part identification, the applicable document revision and the recorded result.

**Student:** So I should describe only the sequence shown in the approved example.

**Instructor:** Exactly. Clear technical communication begins with the correct document.

**Language focus**
- *is shown / is recorded* — passive voice;
- *if something appears inconsistent* — conditional language;
- *refer it to* — report a matter to a responsible person;
- *applicable revision* — the version that applies.

**After listening**

In pairs, one student explains the document fields; the other asks clarification questions:
- Which revision is shown?
- Where is the operation sequence?
- Which checks are identified?
- Who should be contacted if information is unclear?

## 6. Four professional viewpoints

Use the same fictional process-sheet extract provided by the teacher.

- **Technologist:** identify the operation sequence, material reference and planned checks.
- **Programmer:** explain how a digital system might store document revision and process data.
- **Electrician:** explain why an electrical assembly task must use the correct wiring/document revision and authorised instruction.
- **Machine-tool operator:** identify where the drawing reference and dimension requirements would be found; do not invent machine settings.

## 7. Self-check and teacher key

1. What is the purpose of a process sheet?
2. Name two documents it does not replace.
3. What should you do if two values conflict?
4. Practice 1: 1 d; 2 c; 3 a; 4 e; 5 b.
5. Practice 2: b → c → d → a (a simplified classroom order; actual sequence is document-specific).
6. Practice 3: 1 revision; 2 workpiece; 3 non-conformity; 4 traceability.
7. Listening: gist A; details 1 A, 2 A, 3 A, 4 A.

**Writing task:** write 100–120 words explaining why a process sheet must be clear and current.

**Writing rubric (8):** purpose 2; correct vocabulary 2; sequence 1; document control 1; clarity 1; grammar 1.

**Independent work:** create a glossary card for eight terms from this lesson. Include a definition and an original example sentence.

# Lesson 10. Dimensions, Units and Measurement in Engineering

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. read common dimension and measurement terms;
2. distinguish a nominal dimension, measured value and tolerance;
3. recognise common SI units used in introductory engineering texts;
4. read a simple table without confusing units or decimal notation;
5. listen for a measurement report and identify the value and unit;
6. describe a measurement discrepancy without making an unauthorised acceptance decision.

## 1. Lead-in

Discuss:
- Why must a number always be read together with its unit?
- What is the difference between length and mass?
- Why can two values look similar but represent different quantities?
- Why should a measurement be recorded with its unit and instrument/context?

## 2. Vocabulary and units

| English | Russian | Symbol / example |
|---|---|---|
| dimension | размер | The drawing gives the main dimensions. |
| length | длина | millimetre (mm), metre (m) |
| width | ширина | The width is shown in millimetres. |
| height | высота | The height is recorded in mm. |
| diameter | диаметр | Ø is commonly used for diameter. |
| radius | радиус | R may indicate a radius on a drawing. |
| depth | глубина | The depth is stated in the specification. |
| thickness | толщина | Sheet thickness is measured in mm. |
| mass | масса | kilogram (kg) |
| force | сила | newton (N) |
| temperature | температура | degree Celsius (°C), kelvin (K) |
| pressure | давление | pascal (Pa), kilopascal (kPa), bar (unit used in some contexts) |
| measured value | измеренное значение | Record the measured value. |
| nominal dimension | номинальный размер | The nominal dimension is the stated target size. |
| tolerance | допуск | The tolerance defines an allowed variation. |
| measuring instrument | измерительный инструмент | Use the instrument specified by the procedure. |

**Important:** this is a language reference, not a complete unit-conversion or metrology standard. Use the units and notation stated in the supplied drawing or task.

## 3. Reading numbers and units

Examples:
- 25 mm — twenty-five millimetres;
- 1.5 mm — one point five millimetres;
- Ø12 mm — a diameter of twelve millimetres;
- R5 mm — a radius of five millimetres;
- 20 °C — twenty degrees Celsius;
- 2.4 kg — two point four kilograms.

Decimal separators differ between countries and documents. In English-language technical material, a decimal point is common. Always follow the notation convention used by the source document and never silently reinterpret a value.

## 4. Reading: measurement record

Read this fictional training example. The values are invented for language practice and are not aircraft or production acceptance criteria.

| Item | Nominal value | Recorded value | Unit |
|---|---:|---:|---|
| A — length | 50.0 | 50.1 | mm |
| B — width | 20.0 | 20.0 | mm |
| C — thickness | 3.0 | 2.9 | mm |
| D — mass | 1.5 | 1.6 | kg |

### Reading tasks

1. Which item has a nominal length of 50.0 mm?
2. What recorded value is shown for item B?
3. Which item is described by mass rather than a linear dimension?
4. Why must the unit column be read?
5. Can the table alone establish whether a part is acceptable? Explain.
6. What additional document or information might be needed to interpret a tolerance?

**Key concept:** a difference between nominal and recorded values is not, by itself, proof of acceptance or rejection. The applicable tolerance, measurement method, instrument status and approved procedure matter.

## 5. Grammar and language: reporting values

Useful structures:
- **The nominal value is…**
- **The recorded value is…**
- **The measurement is given in millimetres.**
- **The diameter is shown as…**
- **The value differs from the nominal dimension by…**
- **The result should be checked against the applicable specification.**

Comparing:
- *higher than / lower than* for numerical values;
- *equal to* for the same value;
- *approximately* when the source itself indicates an approximation;
- *within / outside the stated range* only when the range is supplied and the comparison is justified.

### Practice 1. Choose the correct unit or term

1. A length is commonly recorded in (mm / kg).
2. Mass is commonly recorded in (kg / mm).
3. The symbol Ø refers to (diameter / temperature).
4. The allowed variation associated with a dimension is called a (tolerance / timetable).
5. A value obtained by measurement is the (measured value / nominal title).

### Practice 2. Read the data

Use the table above.

1. Item A: state the nominal and recorded values.
2. Item C: state the nominal and recorded values.
3. Which two rows use millimetres?
4. Write one sentence explaining why the tolerance column or specification is needed.

## 6. Listening: reporting a measurement

**Before you listen**

Key words: *nominal, measured, diameter, millimetres, record, specification*. Predict what details should be included in a clear measurement report.

**First listening — gist**

What is the student reporting?

A) Values from a fictional training measurement table.  
B) A flight announcement.  
C) A shopping list.

**Second listening — details**

1. What is the nominal length in the example?
   A) 50.0 mm  
   B) 5.0 kg  
   C) 500 °C
2. What value was recorded for item A?
   A) 50.1 mm  
   B) 20.0 mm  
   C) 1.6 kg
3. What does the instructor ask the student to check?
   A) the applicable specification and tolerance  
   B) the weather  
   C) the colour of the instrument
4. Does the instructor accept or reject the item from the table alone?
   A) No; more controlled information is needed.  
   B) Yes; every difference is automatically acceptable.  
   C) Yes; every difference is automatically unacceptable.

**Recording script**

**Student:** I have completed the fictional measurement table. Item A has a nominal length of fifty point zero millimetres.

**Instructor:** What value did you record?

**Student:** Fifty point one millimetres. I have included the unit in the table.

**Instructor:** Good. Does that difference tell you whether the item meets the requirement?

**Student:** Not by itself. I need to check the applicable tolerance and the measurement procedure.

**Instructor:** Correct. You must also use the specified instrument and follow the authorised method. Do not make an acceptance decision from an incomplete example.

**Student:** I will report the value and refer to the specification.

**Instructor:** Exactly. A clear report gives the value, unit and relevant document reference.

**Language focus**
- say *fifty point one millimetres*, not just *fifty point one*;
- *does not tell you whether…* — explaining a limitation;
- *refer to the specification* — consult the controlling document.

**After listening**

Students take turns reporting one row from the training table. The listener checks whether the speaker states the item, nominal value, measured value and unit.

## 7. Four professional viewpoints

- **Technologist:** explain where a nominal dimension and tolerance are found in a controlled drawing or specification.
- **Programmer:** explain why a digital record must preserve units and decimal notation.
- **Electrician:** describe why a measurement report must identify the quantity, unit and relevant test context.
- **Machine-tool operator:** explain why dimensions must be read from the current drawing and checked using the authorised method.

## 8. Self-check and teacher key

2. What is a tolerance?
3. Why must a value include its unit?
4. Practice 1: 1 mm; 2 kg; 3 diameter; 4 tolerance; 5 measured value.
5. Practice 2: 1 nominal 50.0 mm, recorded 50.1 mm; 2 nominal 3.0 mm, recorded 2.9 mm; 3 A, B and C use mm (three rows); 4 the specification/tolerance is needed to interpret whether the recorded value meets the requirement.
6. Listening: gist A; details 1 A, 2 A, 3 A, 4 A.

**Writing rubric (8):** correct item identification 2; values and units 2; distinction between nominal and measured 1; tolerance awareness 1; clarity 1; grammar 1.

# Lesson 11. Technical Word Formation, Abbreviations and Symbols

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. recognise common prefixes, suffixes and compound nouns in technical English;
2. interpret abbreviations only when the context or legend supports them;
3. understand the difference between a symbol, an abbreviation and a unit;
4. read a short technical note and identify key terms;
5. listen to a document-control briefing and identify how unfamiliar abbreviations should be handled;
6. create a small, context-specific glossary.

## 1. Lead-in

Look at the terms *measurement, measurable, unmeasured, pre-processing, electrical, electrically*. What parts of the words repeat? How does the added part change the meaning?

Discuss why guessing the meaning of an abbreviation can be risky.

## 2. Word formation

| Word part | General meaning | Example |
|---|---|---|
| un- | not / opposite | unsafe, unclear |
| re- | again | recheck, reread |
| pre- | before | pre-processing, pre-check |
| non- | not / absence of | non-conformity |
| micro- | small | microcontroller |
| multi- | many | multi-axis |
| -er | person or device that performs an action | programmer, measuring instrument |
| -tion | process or result | inspection, production |
| -ment | process or result | measurement, development |
| -able | can be / suitable for | measurable, readable |
| -al | relating to | electrical, mechanical |
| -ly | forms an adverb | electrically, mechanically |

Word formation can help with reading, but it does not replace checking a technical definition.

## 3. Compound nouns

English technical texts often combine nouns:
- process sheet;
- drawing revision;
- quality record;
- control system;
- measurement result;
- aircraft structure;
- tool data;
- electrical circuit.

The first noun often describes the type or purpose of the second noun. Translate the whole expression, not each word independently.

### Practice 1. Identify the word parts

1. recheck
2. non-conformity
3. measurable
4. electrical
5. pre-processing

For each word, identify the prefix or suffix and explain the general meaning.

### Practice 2. Match the compound noun and meaning

1. drawing revision  
2. measurement result  
3. control system  
4. quality record  
5. process sheet

a) document that describes a planned sequence of operations  
b) recorded outcome of a measurement  
c) version of a drawing  
d) system used to control a process or equipment  
e) record related to quality information

## 4. Abbreviations and symbols

Examples frequently encountered in introductory technical documents:

| Form | Meaning | Important note |
|---|---|---|
| CNC | computer numerical control | context: machine tools and programmed control |
| CAD | computer-aided design | context: digital design |
| CAM | computer-aided manufacturing | context: manufacturing support |
| QA | quality assurance | organisation-specific use may vary |
| QC | quality control | distinguish from QA in the source context |
| ID | identification / identifier | exact meaning depends on the document |
| Rev. | revision | often appears beside a document version |
| No. | number | may identify a part or document |
| mm | millimetre | unit symbol, not an abbreviation to pluralise |
| kg | kilogram | unit symbol |
| Ø | diameter | drawing symbol |
| R | radius | confirm drawing convention |
| ± | plus or minus | meaning depends on the dimension/specification |

**Critical rule:** abbreviations are not universal. A company, college or technical standard may define a local abbreviation differently. Use the document's legend, glossary or approved terminology list. Never guess an unfamiliar safety-critical abbreviation.

## 5. Reading: a short document note

Read:

“Training document: Part ID A-104. Drawing No. D-208, Rev. B. The nominal diameter is shown with the Ø symbol. The measurement unit is millimetres (mm). The process sheet refers to a CNC operation and a quality-control record. Abbreviations used in this exercise are defined in the glossary on the final page. If a term is not listed, ask the instructor rather than assuming its meaning.”

### Reading tasks

2. What is the drawing number?
3. Which revision is shown?
4. Which symbol indicates diameter?
5. Where are the abbreviations defined?
6. What should a student do if an abbreviation is not listed?

### Practice 3. True or false

2. Ø indicates temperature.
3. mm is the unit symbol for millimetre.
4. Every abbreviation has exactly the same meaning in every organisation.
5. The text tells students to ask if a term is not defined.

## 6. Listening: checking an abbreviation

**Before you listen**

Key words: *abbreviation, glossary, revision, context, symbol, confirm*. Predict how a student should deal with an unfamiliar term in a technical document.

**First listening — gist**

What is the instructor explaining?

A) How to interpret abbreviations safely and consistently.  
B) How to choose a holiday destination.  
C) How to design a poster.

**Second listening — details**

1. Where should the student look first?
   A) the document glossary or legend  
   B) a random social media post  
   C) an unrelated textbook
2. Why does context matter?
   A) the same letters can have different meanings  
   B) context changes the unit of every measurement  
   C) abbreviations are always decorative
3. What should the student do if the term is not defined?
   A) ask the responsible instructor  
   B) invent a meaning  
   C) delete the term
4. What should be recorded in a glossary?
   A) the term, meaning and source/context  
   B) only the colour of the page  
   C) a guessed translation

**Recording script**

**Student:** I found an abbreviation in the process document, but it is not in my vocabulary list.

**Instructor:** First, check the glossary or legend attached to that document.

**Student:** What if it is not there?

**Instructor:** Look at the context, but do not rely on a guess. The same letters may have different meanings in different organisations or technical fields.

**Student:** Should I ask you to confirm it?

**Instructor:** Yes. Record the abbreviation, the document title and its revision, then ask the responsible person.

**Student:** I can add the confirmed meaning to our class glossary with its source.

**Instructor:** Exactly. A useful glossary records context, not just a translation.

**Language focus**
- *attached to* — associated with a document;
- *may have different meanings* — possibility;
- *confirm* — check that information is correct;
- *with its source* — record where the definition came from.

**After listening**

Students receive a short teacher-created glossary. In pairs, locate three abbreviations and explain where each definition is confirmed.

# Lesson 12. Reading Technical Descriptions and Specification Tables

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. use headings, labels, tables and units to navigate a technical document;
2. distinguish a description from a requirement;
3. identify part references, revision, dimensions, material and notes in a simplified specification;
4. scan a table for specific information and summarise it accurately;
5. listen to a document-reading task and identify the order of checks;
6. report missing or unclear information using appropriate clarification language.

## 1. Lead-in

Discuss:
- Why are tables useful in technical documents?
- What can a drawing show that a paragraph may not show clearly?
- Why should a reader check the title, revision and units before interpreting a table?
- What is the difference between “the part is made of aluminium” and “the part shall be made of the specified aluminium alloy”?

## 2. Vocabulary

| English | Russian | Example |
|---|---|---|
| specification | спецификация / технические требования | The specification states the requirements. |
| technical description | техническое описание | The description explains the item. |
| requirement | требование | A requirement must be interpreted in context. |
| note | примечание | Read the notes below the table. |
| reference | ссылка / обозначение документа | The drawing reference is listed here. |
| title block | основная надпись чертежа | The title block contains document information. |
| revision | редакция | The revision identifies the document version. |
| material grade | марка материала | The material grade is stated in the specification. |
| nominal size | номинальный размер | The nominal size is shown in the table. |
| tolerance | допуск | The tolerance must be read with the dimension. |
| quantity | количество | The quantity is stated in the parts list. |
| applicable | применимый | Use the applicable document. |
| shall | должен / подлежит (нормативное требование) | “Shall” often indicates a requirement in formal specifications. |
| should | следует / рекомендуется | “Should” often indicates a recommendation. |
| may | может / допускается (по контексту) | “May” can express possibility or permission. |

## 3. Reading strategy: four passes

1. **Identify the document:** title, document number, revision, date and source.
2. **Understand the structure:** headings, table columns, notes, units and legend.
3. **Scan for the requested information:** part number, material, quantity, dimension or requirement.
4. **Check context:** confirm that the value belongs to the correct row, column, revision and unit.

Never treat an isolated number as meaningful without its label and unit.

## 5. Language focus: requirements and recommendations

Compare:
- **shall** — commonly used to state a formal requirement in specifications;
- **should** — commonly used for a recommendation;
- **may** — can express permission or possibility; interpret in context;
- **must** — expresses strong obligation in ordinary instructions and some formal contexts.

Examples:
- The document **shall** include a revision identifier. (requirement in this language exercise)

   B) the paper colour  
   C) the author's favourite subject
2. What should be checked next?
   A) the unit heading  
   B) an unrelated paragraph  
   C) the page decoration
3. What is missing from the training table?
   A) material grades and tolerances  
   B) item descriptions  
   C) all quantities
4. What should the student do about missing information?
   A) ask for clarification  
   B) invent a value  
   C) ignore the notes

**Recording script**

**Instructor:** You have a short component table. Before reading the dimensions, what do you check?

**Student:** The document title, number and revision.

**Instructor:** Good. What comes next?

**Student:** The unit heading, then the row and column labels.

**Instructor:** Exactly. Find the item description and make sure the number belongs to the correct item.

**Student:** The table gives nominal sizes and quantities, but it does not show material grades or tolerances.

**Instructor:** Correct. Can you use it as a complete manufacturing instruction?

**Student:** No. I should refer to the required drawing and specification, or ask for the missing information.

**Instructor:** Well done. A careful reader reports what the document contains and what it does not contain.

**Language focus**
- *belongs to the correct item* — matching data with its row;
- *does not show* — identifying missing information;
- *refer to* — consult a source;
- *what the document contains* — accurate reporting.

**After listening**

Pairs receive a second teacher-created table. Student A asks for three values; Student B finds each value and states its row, column and unit. Then they identify one missing piece of information.
