# Technical English — Course 3, Semester 2 — Lessons 6–8
## CNC machine components, axes, coordinates and basic G-code reading

**Status:** original draft lessons for the provisional five-year course map; not imported into the portal or approved as official programme content.  
**Level:** B1–B1+ ESP.  
**Professional focus:** machine-tool operators, technologists and programmers; supporting vocabulary for electricians working with machine electrical/control documentation.  
**Audio:** original Spotlight-style scripts for future recording; no MP3 files or player are included.  
**Safety boundary:** all CNC code is fictional reading practice. It must not be entered into or run on real equipment. Actual operation requires authorised training, approved programmes, machine-specific documentation and supervision.

## Block outcomes

Students will be able to:
- name common CNC machine components and describe their general functions;
- understand axis, coordinate, origin, reference point and work offset vocabulary;
- read the structure of a short, fictional G-code text sample without executing it;
- identify programme lines, comments, sequence numbers and common command categories at an introductory language level;
- ask for clarification and report uncertainty instead of guessing machine settings.

# Lesson 6. CNC Machine Components and Setup Vocabulary

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. identify common parts of a CNC machine in a labelled educational diagram;
2. describe the general function of the spindle, worktable, tool magazine, enclosure and control panel;
3. distinguish a machine component from a cutting tool and a workpiece;
4. use location and function phrases to describe a machine layout;
5. listen to a basic machine overview and identify component functions;
6. explain why setup information must be checked by an authorised person.

## 1. Lead-in

Discuss:
- What makes a CNC machine different from a manually controlled machine tool?
- Why does an operator need to identify the main components?
- What information might be displayed on a control panel?
- Why is a diagram not a substitute for machine-specific operating instructions?

| worktable | рабочий стол | The worktable supports the workholding arrangement. |
| workpiece | заготовка / обрабатываемая деталь | The workpiece is identified in the job documentation. |
| cutting tool | режущий инструмент | The cutting tool removes material. |
| tool holder | инструментальная оправка / держатель | The tool holder secures the tool. |
| tool magazine | магазин инструментов | A tool magazine stores tools on some machines. |

## 3. Reading: a simplified machine overview

Read:

“A CNC machining centre combines mechanical components, a control system and supporting equipment. The spindle provides the rotation required by a particular machining operation. The worktable supports the workholding arrangement, while a fixture may locate the workpiece. Some machines include a tool magazine that stores several tools. The control system reads a programme and coordinates machine functions within the limits of the machine configuration. An enclosure helps protect the working area and contains chips or coolant.

The exact arrangement differs between machine models. Component names and operating limits must be checked in the manufacturer's documentation. A student should identify components from the training diagram but must not use the diagram as a setup or operating instruction.”

### First reading — gist

A) The text introduces common CNC machine components and their general functions.  
B) The text gives a complete machine setup procedure.  
C) The text explains how to bypass machine protection.

### Second reading — details

1. What does the spindle provide?
2. What does the worktable support?
3. What is the purpose of a fixture?
4. What may a tool magazine store?
5. What does the enclosure help contain?
6. Why must the machine model documentation be checked?

**Recording script — reveal after listening**

**Instructor:** Look at the training diagram. The spindle is shown above the work area.

**Student:** Is that the component that provides rotation?

**Instructor:** Yes, for the machine configuration shown. The worktable supports the workholding arrangement, and a fixture may locate the workpiece.

**Student:** I can also see a tool magazine on the side.

**Instructor:** Correct. Some machines use a magazine to store several tools. The enclosure surrounds the working area, and the control panel displays machine information.

**Student:** Does this diagram show the exact setup procedure?

**Instructor:** No. It is a vocabulary diagram only. Always use the machine-specific documentation and authorised instruction for actual operation.

**Language focus:** *is shown*, *is located*, *supports*, *may store* — describing location, function and possibility.

**After listening:** In pairs, describe five labelled components without looking at the vocabulary table. The listener identifies each component on the diagram.

# Lesson 7. Machine Axes, Coordinates and Reference Points

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. understand introductory vocabulary for axes and coordinate systems;
2. distinguish an axis from a coordinate value and a reference point;
3. read a simple two-dimensional coordinate grid;
4. understand the language of machine origin, work coordinate system and reference position at an introductory level;
5. listen to an explanation of a diagram and identify the coordinate terms;
6. describe a coordinate diagram without giving machine setup instructions.

## 1. Lead-in

Look at a simple Cartesian grid. Discuss:
- What does the horizontal axis show?
- What does the vertical axis show?
- How is a point represented?
- Why must a coordinate system be clearly identified?

## 2. Vocabulary

| English | Russian | Example |
|---|---|---|
| axis (plural axes) | ось (оси) | The diagram shows two axes. |
| X-axis | ось X | The X-axis is horizontal in this example. |
| Y-axis | ось Y | The Y-axis is vertical in this example. |
| Z-axis | ось Z | The Z-axis is commonly associated with a third direction. |
| coordinate | координата | A coordinate identifies a position in a system. |
| coordinate system | система координат | The point is described in a coordinate system. |
| origin | начало координат | The origin is the zero point of the illustrated grid. |
| reference point | опорная / исходная точка | A reference point provides a defined reference. |
| position | положение | The position is shown on the diagram. |
| direction | направление | The arrow indicates a direction. |
| positive / negative | положительный / отрицательный | The axis has positive and negative directions. |
| work coordinate system | рабочая система координат | The term appears in CNC documentation. |
| machine coordinate system | система координат станка | The term identifies a machine-related coordinate frame. |
| offset | смещение / коррекция (по контексту) | An offset changes a coordinate relationship. |
| reference return | возврат в референтное положение | Machine-specific function; consult documentation. |

## 3. Reading: coordinate systems in a diagram

Read:

“A coordinate system provides a consistent way to describe position. In a simple two-dimensional Cartesian grid, the horizontal direction is labelled X and the vertical direction is labelled Y. The point (3, 2) is located three units along the positive X direction and two units along the positive Y direction from the origin. A three-dimensional system adds a third axis, commonly labelled Z.

CNC documentation may refer to a machine coordinate system and a work coordinate system. These terms describe different references used by a control system. Their exact meaning and use depend on the machine and its documentation. A classroom diagram can help students understand the words, but it cannot establish machine zero, work offsets or a safe machine position.”

### First reading — gist

A) The text explains basic coordinate vocabulary and distinguishes diagram learning from machine setup.  
B) The text teaches students to set machine zero.  
C) The text describes a cutting tool.

### Second reading — details

1. Which direction is labelled X in the two-dimensional example?
2. Which direction is labelled Y?
3. What does the point (3, 2) represent?
4. What additional axis appears in a three-dimensional system?
5. Does the classroom diagram establish a real machine reference position?
6. Why must CNC coordinate terms be interpreted with machine documentation?

## 4. Coordinate grid practice

Use the simple grid supplied by the teacher.

1. Find point A (2, 1).
2. Find point B (4, 3).
3. Write the coordinates of a point shown at X = 1 and Y = 4.
4. Explain what the first number represents in the ordered pair (x, y).
5. Explain why a coordinate has no useful meaning unless its coordinate system is known.

**Teacher note:** use a paper or on-screen educational grid only. Do not connect this exercise to real machine movement or controller input.

- **The X-coordinate is…**
- **The Y-coordinate is…**
- **The origin is marked as…**
- **The arrow points in the positive direction.**
- **The diagram represents…**

## 6. Listening: explaining a coordinate diagram

**Before you listen**

A) A basic coordinate grid.  
B) A real machine setup.  
C) A safety evacuation.

**Second listening — details**

   A) X B) Y C) Z
2. Where is the origin?

3. What does (3, 2) mean?

**Recording script**

**Instructor:** This is a simple two-dimensional coordinate grid. The horizontal axis is X, and the vertical axis is Y.

**Student:** The origin is where the two axes meet?

**Instructor:** Correct. It is marked as zero, zero. The point (3, 2) is three units in the positive X direction and two units in the positive Y direction.

**Student:** What happens in three dimensions?

**Instructor:** A third axis, usually called Z, is added to the diagram.

**Student:** Does this explain how to set a CNC machine reference?

**Instructor:** No. It teaches coordinate vocabulary only. Machine coordinate systems and work offsets are machine-specific and must be handled using approved documentation and authorised training.

**Language focus:** *is marked as*, *is located at*, *in the positive direction*.

**After listening:** Students explain three points on the paper grid using ordered pairs.

# Lesson 8. G-code: Reading Basic Program Blocks and Comments

**Suggested time:** 90 minutes

## Learning outcomes

Students will:
1. understand the terms G-code, programme, block, address, command and comment;
2. recognise the general layout of a simple programme text;
3. identify line numbers, letter addresses and comments in a fictional extract;
4. recognise a few common command names as reading vocabulary only;
5. listen to a discussion about how to read a programme extract responsibly;
6. explain why code interpretation depends on controller, machine configuration and approved documentation.

## 1. Lead-in

Discuss:
- What is a computer numerical control programme?
- Why does a machine need instructions in a defined format?
- Why can the same code word have machine-specific details?
- Why is reading a printed example different from running a programme?

## 2. Vocabulary

| English | Russian | Example |
|---|---|---|
| G-code | язык программирования ЧПУ / G-код | G-code is used in many CNC contexts. |
| programme | управляющая программа | The programme contains blocks of information. |
| block | кадр / блок программы | A block is one line or unit of programme text. |
| line number | номер кадра / строки | A line number can identify a block. |
| address | адресное обозначение | A letter address introduces a type of value. |
| command | команда | A command has a defined meaning for a control. |
| comment | комментарий | A comment explains the example for a reader. |
| modal command | модальная команда | A command may remain active until changed, depending on the control. |
| feed rate | скорость подачи | Meaning and units depend on the mode and control. |
| spindle speed | частота вращения шпинделя | The value and units depend on the programme context. |
| coordinate word | координатное слово | A coordinate word contains an axis address and value. |
| tool call | вызов инструмента | Exact syntax is control-specific. |
| programme end | конец программы | End conventions depend on the controller. |
| controller | система ЧПУ / контроллер | The controller interprets programme data. |
| syntax | синтаксис | Syntax defines how programme text is written. |

## 3. Reading: what is a programme block?

Read:

“A CNC programme is commonly presented as a sequence of blocks. A block may contain a sequence number, one or more address letters with values, commands and optional comments. The exact format depends on the controller and the machine configuration. A letter such as X may introduce a coordinate value in a particular context, while other address letters can represent different types of information.

Comments are included to help a human reader understand an example. They are not a substitute for the controller's programming manual. A programme that looks simple on paper may have important effects when interpreted by a specific machine. Students should learn to recognise the text structure in a classroom example but must never enter, edit or run a programme on real equipment without the required authorisation and supervision.”

### First reading — gist

A) The text explains the structure of CNC programme text and its limits.  
B) The text gives permission to run sample code.  
C) The text explains how to bypass a controller.

### Second reading — details

1. What is a programme block?
2. What may a block contain?
3. What is the purpose of a comment?
4. Why does the controller matter?
5. What must students not do with classroom sample code?
6. Which document should be consulted for control-specific syntax?

## 4. Fictional programme text — reading only

The following lines are invented for visual language analysis. They are **not executable instructions** and are deliberately incomplete. Do not enter them into a machine or simulator.

```text
N010 (TRAINING EXAMPLE — READ ONLY)
N020 (PART: SAMPLE BLOCK)
N030 (X AND Y ARE ADDRESS LETTERS IN THIS EXAMPLE)
N040 (CHECK CONTROLLER DOCUMENTATION)
N050 (END OF CLASSROOM EXTRACT)
```

This extract contains comments and line identifiers only. It does not define a machining operation.

### Practice 1. Identify the text features

1. Which character introduces a line identifier?
2. Which part of the line is a comment?
3. Does the extract contain a complete machining command?
4. Why is the phrase READ ONLY important?
5. What should a student do before interpreting a real programme?

## 5. Language focus: explaining code structure

Useful phrases:

## 6. Listening: reading a programme extract responsibly

**Before you listen**

Key words: *block, address, comment, controller, syntax, read-only*. Predict what an instructor will tell students before they study a printed programme extract.

**First listening — gist**

What is the instructor explaining?

A) How to recognise programme structure without executing it.  
B) How to start a real CNC machine.  
C) How to repair a controller.

**Second listening — details**

1. What identifies a block in the printed example?
   A) a line number B) a photograph C) a material colour
2. What does a comment do?
   A) helps explain the text to a reader B) guarantees machine safety C) replaces the controller manual
3. Why must the controller documentation be checked?
   A) syntax and behaviour can depend on the control B) all controls are identical C) comments define every machine limit
4. What is the student allowed to do with the classroom extract?
   A) read and discuss its structure B) run it on a machine C) change a production programme

**Recording script**

**Instructor:** Today we are reading a printed CNC programme extract. We are not running it.

**Student:** The lines begin with an N number. Is that a line identifier?

**Instructor:** In this example, yes. The text in parentheses is a comment for the reader.

**Student:** I can see the letters X and Y in the explanation. Do they always mean the same thing on every controller?

**Instructor:** You must check the relevant programming documentation. The exact format and behaviour depend on the controller and machine configuration.

**Student:** So I should identify the block, address and comment, but not treat this page as an operating instruction.

**Instructor:** Correct. Never enter or run classroom sample code on real equipment.

**Language focus:** *begins with*, *in this example*, *depends on*, *must check*, *read-only*.

**After listening:** Students annotate a teacher-provided, non-executable text extract by marking line identifiers, comments and unfamiliar terms. The teacher confirms the interpretation.

- **Electrician:** explain why control-system documentation and authorised electrical service information must not be replaced by guesses based on code text.
