# English Technical Semester Assessment — Draft v8 (Questions 141–160)

Статус: черновик для предметной и методической экспертизы. Не импортировать в защищённый банк и не показывать студентам до проверки. Задания проверяют профессиональную коммуникацию и чтение технических данных; они не являются инструкциями по выполнению работ.

## Questions

**141.** Choose the correct completion: “The inspection findings ___ in the final report.”
- A. are summarized
- B. is summarized
- C. summarizes
- D. summarizing

**142.** What does *traceability* mean in quality management?
- A. The ability to follow the history, location or use of an item or record
- B. The ability to change a product's colour
- C. The time needed to transport a product
- D. The number of employees in a department

**143.** Complete the sentence: “The replacement part is compatible ___ the existing assembly.”
- A. with
- B. for
- C. by
- D. at

**144.** A specification states: “The maximum operating pressure is 8 bar.” Which value is within this stated maximum?
- A. 8.5 bar
- B. 7.5 bar
- C. 9 bar
- D. 10 bar

**145.** Choose the most suitable wording for a technical email.
- A. “Confirm me if drawing approved one.”
- B. “Please confirm whether the attached drawing is the approved revision.”
- C. “You confirming drawing was approval?”
- D. “Please to confirm attached drawing approve.”

**146.** What is the main purpose of a *non-conformance report*?
- A. To announce a staff promotion
- B. To list all routine deliveries
- C. To advertise a new product
- D. To document a product, process or result that does not meet specified requirements

**147.** Complete the sentence: “The operator reported that the display ___ intermittently.”
- A. were flickering
- B. was flickering
- C. flicker
- D. has flicker

**148.** A graph shows that vibration increased from 2.0 mm/s to 2.6 mm/s. What was the increase?
- A. 0.4 mm/s
- B. 2.6 mm/s
- C. 4.6 mm/s
- D. 0.6 mm/s

**149.** What does *obsolete* mean when it describes a technical document?
- A. Newly approved
- B. Ready for translation
- C. No longer current or recommended for use
- D. Missing a page number only

**150.** Choose the correct completion: “The test results should be retained ___ future reference.”
- A. since
- B. during
- C. for
- D. among

**151.** Which phrase best introduces a limitation in a technical report?
- A. “The results prove everything in all situations.”
- B. “No limitations can ever apply.”
- C. “The results are limited to the conditions described in this test.”
- D. “The test conditions do not matter.”

**152.** A component datasheet lists a *nominal voltage* of 12 V. What does *nominal* generally indicate?
- A. A stated or designated value, not necessarily the exact value under every condition
- B. A guaranteed measured value at every instant
- C. The component's physical length
- D. The date the datasheet was printed

**153.** Complete the sentence: “The technician asked the supplier ___ the latest datasheet.”
- A. provide
- B. providing
- C. provided
- D. to provide

**154.** What is a *handover* in a maintenance or production team?
- A. The disposal of all technical records
- B. A change in the product's colour
- C. A measurement taken without a reference
- D. The transfer of relevant information and responsibility between people or shifts

**155.** Read the note: “The replacement is functionally equivalent but has a different part number.” What is stated?
- A. It is identical in every respect and has the same part number
- B. It cannot perform the required function
- C. It performs an equivalent function, but its identifier differs
- D. Its part number has not been assigned

**156.** Choose the correct completion: “No data ___ available for the second test condition.”
- A. are
- B. is
- C. be
- D. have

**157.** What does *environmental monitoring* commonly involve in an industrial setting?
- A. Monitoring employees' personal entertainment choices
- B. Recording only the colour of products
- C. Replacing all production records
- D. Measuring and recording relevant environmental conditions or emissions

**158.** Choose the best connector: “The revised component passed the dimensional check; ___, its documentation still requires approval.”
- A. because
- B. however
- C. therefore
- D. for example

**159.** A network diagnostic report states: “Packet loss was detected on the connection.” What does this indicate?
- A. Every data packet arrived twice
- B. The network has no connected devices
- C. Some data packets did not reach their intended destination
- D. The connection speed was measured in kilograms

**160.** Which detail is most useful when reporting an issue with a CNC program file to a programming team?
- A. The colour of the office walls
- B. File name and revision, machine or controller context, observed message and reproducible description
- C. The programmer's preferred lunch
- D. A statement that the file “looks strange” without further detail

## Teacher key and rationale

| No. | Key | Rationale |
|---:|:---:|---|
| 141 | A | “Findings” is plural and takes “are summarized”. |
| 142 | A | Traceability links an item or record to its relevant history and movement. |
| 143 | A | The standard collocation is “compatible with”. |
| 144 | B | 7.5 bar is below the stated maximum of 8 bar. The item tests reading a stated limit, not an operating recommendation. |
| 145 | B | The sentence is a clear and polite request for confirmation. |
| 146 | D | A non-conformance report documents a failure to meet requirements. |
| 147 | B | “Display” is singular; past continuous describes the reported intermittent behaviour. |
| 148 | D | 2.6 − 2.0 = 0.6 mm/s. |
| 149 | C | An obsolete document is outdated and should not be treated as current. |
| 150 | C | The fixed phrase is “for future reference”. |
| 151 | C | It explicitly limits the scope of the reported findings. |
| 152 | A | A nominal value is a designated reference value; actual values may vary within applicable conditions and tolerances. |
| 153 | D | “Ask someone to do something” takes an object + infinitive. |
| 154 | D | A handover transfers information and responsibility between people or shifts. |
| 155 | C | The note distinguishes functional equivalence from identical identification. |
| 156 | A | “Data” is treated as plural in this item; “are available” is the expected form. Align with the course style guide. |
| 157 | D | Environmental monitoring measures and records relevant environmental parameters. |
| 158 | B | “However” contrasts successful dimensional checking with pending documentation approval. |
| 159 | C | Packet loss means packets fail to reach the intended destination. |
| 160 | B | Identifiers, revision, system context and reproducible observations make a report actionable. |
