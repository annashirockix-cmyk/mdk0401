# Aviation Technical English — listening pilot scripts 2–4

This is an additive companion to `english-listening-lesson-standard-v1.md`. It supplies original audio-recording scripts and listening tasks for the electrician, programmer and machine-tool pathways. Together with the dimensional-inspection sample, the pilot now covers all four professional pathways.

No existing lecture, test, VPR content or runtime file is replaced by this document. Audio recordings are not yet produced; the scripts below are recording masters.

## Pilot 2 — Electricians

**Linked lecture topics:** Technical English Unit 4.1–4.2 (conductors, semiconductors, current and units), Unit 5.1–5.2 (circuit components, series and parallel circuits), Unit 7.2 (electronic circuits), Unit 11.1 (maintenance).

**Title:** Electrical inspection handover  
**Level:** B1  
**Target duration:** 75–95 seconds  
**Learning outcomes:** identify a reported electrical symptom, understand a measured value and circuit reference, distinguish observation from diagnosis, and report the next step clearly.

### Before you listen

Key phrases:
- wiring diagram — a drawing showing electrical connections;
- connector — a device joining conductors;
- continuity test — a test checking whether an electrical path is complete;
- intermittent — occurring sometimes, but not continuously;
- isolate — separate equipment from an energy source under an approved procedure.

Prediction: What details should an electrician include when handing over an intermittent fault?

### Recording script

**Technician:** Morning, Alex. I’m handing over the inspection report for the aircraft training panel, circuit E-14.

**Electrician:** What did you observe?

**Technician:** The indicator did not illuminate during the first check. It worked during the second check, so the symptom appears to be intermittent.

**Electrician:** Did you compare the connector reference with the wiring diagram?

**Technician:** Yes. The connector identification matches drawing revision B. I recorded the test conditions and the equipment ID in the maintenance log.

**Electrician:** Is there a confirmed cause?

**Technician:** No. The report describes the symptom only. It does not identify a failed component.

**Electrician:** Good. Keep the panel out of service and refer the report to the authorised instructor for the next approved test. Do not change the wiring or replace a component on assumption.

**Technician:** Understood. I’ll attach the report and mark the status as “awaiting review”.

### First listening — main idea

1. What is the conversation about?
   A) A change to a passenger cabin layout
   B) A handover concerning an intermittent electrical symptom
   C) A CNC tool replacement
   D) A material delivery

2. Has the cause of the fault been confirmed?
   A) Yes, the indicator is definitely defective
   B) Yes, the connector is damaged
   C) No, only the symptom has been recorded
   D) No, because no inspection was performed

### Second listening — details

3. What is the circuit reference?
   A) E-14
   B) E-40
   C) B-14
   D) E-41

4. Which drawing revision is mentioned?
   A) A
   B) B
   C) C
   D) D

5. How did the indicator behave?
   A) It illuminated continuously
   B) It never illuminated
   C) It illuminated only when the panel was switched off
   D) It did not illuminate at first but worked during the second check

6. What must happen next?
   A) Replace the indicator immediately
   B) Change the wiring
   C) Refer the report for an authorised next test
   D) Delete the maintenance log

### Language focus

7. “The report describes the symptom only” means that the report:
   A) confirms the exact cause
   B) records what was observed without claiming a confirmed cause
   C) gives permission to repair the equipment
   D) replaces the wiring diagram

8. Choose the clearest handover statement:
   A) “The panel is bad, probably.”
   B) “I fixed something, but I do not remember what.”
   C) “The indicator failed during the first check and operated during the second; the cause is not confirmed.”
   D) “The diagram is old, so we ignored it.”

### After listening

In pairs, one student gives a handover and the other asks:
- Which circuit or equipment ID is involved?
- What exactly was observed?
- Which document revision was checked?
- Is the cause confirmed?
- What is the authorised next step?

Write a short handover note using observation, evidence and status as separate pieces of information.

### Transcript reveal

Reveal the script only after the listening tasks are submitted or the student selects “Show transcript” in practice mode.

### Teacher/server key

## Pilot 3 — Programmers

**Linked lecture topics:** Technical English Unit 9.1–9.3 (hardware, software, computers and the Internet), Unit 10.1–10.2 (automation and sensors), Unit 8.2 (networks and topologies).

**Title:** Reviewing aircraft sensor data  
**Level:** B1+/B2  
**Target duration:** 90–110 seconds  
**Learning outcomes:** understand a short technical briefing, identify a data-validation problem, interpret timestamps and distinguish a software warning from a confirmed equipment fault.

### Before you listen

Key phrases:
- sensor reading — a value reported by a sensor;
- timestamp — the recorded date and time of an event;
- data validation — checking that data meets defined rules;
- out of range — outside the permitted interval;
- duplicate record — a record stored more than once.

Prediction: Why might a maintenance dashboard show an incorrect warning even when the sensor is operating normally?

### Recording script

**Systems engineer:** Have you checked the temperature-monitoring dashboard for the aircraft systems training rig?

**Programmer:** Yes. The dashboard shows three high-temperature warnings from yesterday’s test session.

**Systems engineer:** Does the raw data confirm all three warnings?

**Programmer:** Not yet. Two records have the same sensor ID and timestamp. They may be duplicates created during data synchronisation.

**Systems engineer:** What about the third record?

**Programmer:** Its value is above the configured threshold, but the unit field is missing. We cannot compare it reliably until the data format is validated.

**Systems engineer:** Have you changed the threshold?

**Programmer:** No. I have kept the original configuration. I added a validation warning and flagged the three records for review.

**Systems engineer:** Good. Record the software version, the test session ID and the affected timestamps. The dashboard supports investigation, but it does not prove that the aircraft equipment has failed.

**Programmer:** Understood. I’ll prepare a short incident summary and send it to the test engineer.

### First listening — main idea

1. What problem is being reviewed?
   A) A missing aircraft component
   B) High-temperature warnings on a monitoring dashboard
   C) A damaged CNC cutting tool
   D) A change to a wiring diagram

2. What is the programmer's main concern?
   A) The data may be duplicated or incomplete
   B) The monitor is too small
   C) The aircraft is ready for flight
   D) The network cable is too long

### Second listening — details

3. How many warnings are displayed?
   A) One
   B) Two
   C) Three
   D) Four

4. What is unusual about two records?
   A) They have different sensor IDs and dates
   B) They have the same sensor ID and timestamp
   C) They contain no numerical values
   D) They were recorded by different aircraft

5. What is missing from the third record?
   A) The sensor ID
   B) The timestamp
   C) The software version
   D) The unit field

6. What did the programmer change?
   A) The configured temperature threshold
   B) The aircraft hardware
   C) Nothing in the original threshold; a validation warning was added
   D) The sensor ID

7. Which details must be included in the incident summary?
   A) Software version, test session ID and affected timestamps
   B) Passenger names and seat numbers
   C) Aircraft paint colour and delivery date
   D) Staff holiday dates

### Language focus

8. In the conversation, “does not prove that the aircraft equipment has failed” means:
   A) the dashboard is always correct
   B) a warning alone is not sufficient evidence of equipment failure
   C) the sensor must be removed
   D) the data should be deleted

9. Choose the best technical summary:
   A) “Three warnings appeared. Two records may be duplicates; one lacks a unit field. The threshold was not changed.”
   B) “The aircraft definitely has three failed sensors.”
   C) “The dashboard is wrong, so all warnings were deleted.”
   D) “The programmer changed the threshold until the warnings disappeared.”

### After listening

Students work in pairs. One is a programmer; the other is a test engineer. Explain:
- which records require review;
- what information is missing or duplicated;
- why the threshold was not changed;
- what evidence is needed before making a technical conclusion.

Write a three-line incident summary.

### Transcript reveal

Reveal the script only after the listening tasks are submitted or the student selects “Show transcript” in practice mode.

### Teacher/server key

1 B; 2 A; 3 C; 4 B; 5 D; 6 C; 7 A; 8 B; 9 A.

## Pilot 4 — Machine-tool operators

**Linked lecture topics:** Technical English Unit 1.1–1.3 (materials and metal processes), Unit 2.1–2.2 (technical drawing and CAD/CAM), Unit 3.1–3.3 (machining and CNC), Unit 11.1 (maintenance).

**Title:** CNC setup and first-off inspection  
**Level:** B1  
**Target duration:** 85–105 seconds  
**Learning outcomes:** understand a setup briefing, identify a drawing/program revision mismatch, follow a production sequence, and report a first-off measurement.

### Before you listen

Key phrases:
- setup sheet — a document describing the approved machine setup;
- tool offset — a value used by the CNC control to position a tool correctly;
- drawing revision — the identified version of an engineering drawing;
- first-off inspection — inspection of the first produced part before the batch proceeds;
- release — formal permission to continue to the next production stage.

Prediction: What should an operator check if the CNC program and drawing show different revision levels?

### Recording script

**Production technologist:** Before we start the bracket batch, please confirm the job package.

**CNC operator:** The work order is 5082. The drawing is AB-204, revision C. The material certificate matches the specified aluminium alloy.

**Production technologist:** And the CNC program?

**CNC operator:** The file name is AB204_C, but the header shows revision B.

**Production technologist:** Then the package is not consistent. Do not start the cycle. We need document control to confirm the released program.

**CNC operator:** Understood. I’ll keep the machine in the approved safe state and report the mismatch.

**Production technologist:** Once the correct revision is released, check the setup sheet and tool offsets. The first component must pass inspection before the batch continues.

**CNC operator:** What dimensions are listed for the first-off check?

**Production technologist:** The hole diameter and the overall length. Record both measured values against the drawing limits.

**CNC operator:** I’ll wait for the corrected program and the release confirmation.

### First listening — main idea

1. Why does the operator stop before machining?
   A) The material is missing
   B) The CNC program revision does not match the drawing revision
   C) The machine has no operator
   D) The inspection room is closed

2. What is the main purpose of the first-off inspection?
   A) To check the first component before the batch continues
   B) To calculate staff working hours
   C) To select a new material supplier
   D) To update the aircraft flight plan

### Second listening — details

3. What is the work order number?
   A) 204
   B) 5028
   C) 5082
   D) 5802

4. Which revision is shown on the drawing?
   A) A
   B) B
   C) C
   D) D

5. Which revision appears in the CNC program header?
   A) A
   B) B
   C) C
   D) D

6. What should happen before the cycle starts?
   A) The operator should choose either revision
   B) The mismatch should be ignored
   C) The correct released program should be confirmed
   D) The material certificate should be deleted

7. Which dimensions are included in the first-off check?
   A) Hole diameter and overall length
   B) Weight and paint thickness
   C) Tool length and room temperature
   D) Voltage and current

### Language focus

8. “The package is not consistent” means:
   A) all documents contain matching information
   B) some documents show conflicting revision information
   C) the batch has passed inspection
   D) the material has been rejected

9. Choose the most appropriate operator response:
   A) “I’ll use revision B because it is already on the machine.”
   B) “I’ll start the cycle and ask later.”
   C) “I’ll wait for confirmation of the correct released program.”
   D) “I’ll edit the drawing myself.”

### After listening

Role-play a setup briefing. The operator must report the work order, drawing revision, program revision and release status. The technologist must confirm what needs to be checked before production can continue.

Write a short production handover note stating the mismatch and current status.

## Pilot review checklist

Before recording:
- Have an English teacher review grammar, naturalness and level.
- Have a subject teacher review terminology and technical plausibility.
- Confirm that spoken numbers and identifiers are unambiguous.
- Keep the scenario educational. It is not an instruction to operate or maintain real aircraft or machinery.

After recording:
- Compare the recording with the approved script word for word.
- Check volume, clipping, pronunciation of letters/numbers, and playback on desktop/mobile.
- Ensure each audio asset has a stable ID and file path.
- Keep the transcript and answer key out of the pre-submission student payload.
- Test all answer keys against the actual audio, not only against the written script.
