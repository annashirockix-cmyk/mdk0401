# Ресурсы интерфейса

- `fonts/` — шрифты интерфейса и декоративные гарнитуры.
- `fonts/collections/` — дополнительные семейства шрифтов, собранные из ранее импортированных наборов.
- `images/` — иллюстрации, мемы, значки и изображения интерфейса.
- `images/backgrounds/` — фоновые изображения портала.
- `certificates/backgrounds/` — шесть готовых фоновых макетов сертификатов; выбираются на странице сертификата.

Пути к этим ресурсам используются из CSS и генератора рабочих тетрадей. Не переименовывайте файлы без обновления ссылок.
