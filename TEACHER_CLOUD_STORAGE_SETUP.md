# Подключение личных облачных хранилищ преподавателей

Поддерживаемые провайдеры: Google Drive, Яндекс Диск, Microsoft OneDrive и Dropbox.

## OAuth-параметры Apps Script

Откройте проект Apps Script → «Настройки проекта» → «Свойства скрипта» и добавьте пары ключей для каждого провайдера, который планируете подключать. Client ID и Client Secret создаются в кабинете соответствующего OAuth-провайдера; портал не генерирует их автоматически. Не присылайте секреты в чат и не добавляйте их в репозиторий.

Добавьте в Script Properties пары ключей:

| Провайдер | Client ID | Client Secret |
|---|---|---|
| Google Drive | GOOGLE_OAUTH_CLIENT_ID | GOOGLE_OAUTH_CLIENT_SECRET |
| Яндекс Диск | YANDEX_OAUTH_CLIENT_ID | YANDEX_OAUTH_CLIENT_SECRET |
| OneDrive | ONEDRIVE_OAUTH_CLIENT_ID | ONEDRIVE_OAUTH_CLIENT_SECRET |
| Dropbox | DROPBOX_OAUTH_CLIENT_ID | DROPBOX_OAUTH_CLIENT_SECRET |

Redirect URI для всех приложений — точный URL веб-приложения с параметром `?action=cloudOAuthCallback` (например, `https://script.google.com/macros/s/…/exec?action=cloudOAuthCallback`). Скопируйте фактическое значение из `ScriptApp.getService().getUrl()` и добавьте параметр; регистрируйте именно этот полный адрес у каждого провайдера. Для Google используйте scope drive.file; для Яндекс Диска — cloud_api:disk.app_folder; для OneDrive — Files.ReadWrite.AppFolder, User.Read и offline_access; Dropbox — App Folder app type и scopes account_info.read, files.content.read, files.content.write.

## Ограничения и безопасность

- Включайте только необходимые папки/права приложения, не полный доступ ко всему диску.
- Секреты OAuth не добавляйте в GitHub, HTML или клиентский JavaScript.
- Токены хранятся в Script Properties на стороне Apps Script, не в таблице учеников и не в браузере. Владельцы/редакторы проекта Apps Script могут просматривать Script Properties; доступ к редакторам проекта должен быть ограничен доверенными администраторами.
- В редакторе курса можно выбрать подключённый диск для новых файлов темы и вложений к лекциям. Файлы сохраняются в закрытой области приложения и выдаются студентам через сервер портала только после проверки доступа к дисциплине и теме.
- Токены обновляются сервером автоматически по refresh token. При отзыве доступа у провайдера потребуется переподключить диск.
- Нельзя отключить диск, пока в нём остаются прикреплённые учебные файлы: сначала удалите их из материалов или перенесите в другое хранилище.
- Тексты лекций, тесты, карточки и другие записи авторского контента продолжают храниться в таблицах портала как рабочая копия. В разделе «Мои хранилища» доступен ручной экспорт этих записей в JSON-файл выбранного облака. Это резервная копия, а не постоянная синхронизация: после новых изменений создайте копию повторно. Существующие файлы автоматически не переносятся.


## Резервные копии авторских материалов

В разделе «Мои хранилища» преподаватель может вручную создать JSON-резервную копию в каждом подключённом облаке. Копия содержит записи CourseContent, созданные текущим преподавателем в доступных ему дисциплинах: лекции, тесты, карточки, объявления, игры, темы и метаданные вложений. В копию включаются бинарные вложения PDF, DOC и DOCX размером до 3,5 МБ каждое, суммарно до 8 МБ на архив. Файлы встраиваются в JSON как Base64, поэтому архив самодостаточен. Оценки, попытки, результаты и данные студентов исключены. Восстановление из архива пока не реализовано; автоматической синхронизации нет. История последних копий видна только владельцу.


## Первый запуск после настройки OAuth

1. Разверните новую версию Apps Script как веб-приложение.
2. В настройках OAuth каждого выбранного провайдера зарегистрируйте точный Redirect URI из таблицы выше. Он должен совпадать посимвольно.
3. В Apps Script добавьте Client ID и Client Secret только для тех провайдеров, которые уже настроены.
4. Откройте портал под учётной записью преподавателя → «Мои хранилища» → «Подключить».
5. После успешного подключения проверьте тестовую загрузку небольшого PDF или DOCX в редакторе курса, затем скачивание от имени студента с открытым доступом к материалу.
6. Для резервной копии нажмите «Создать резервную копию» на карточке подключённого диска. Копия создаётся вручную; автоматического расписания и восстановления из архива пока нет.

Если у провайдера ещё нет OAuth-приложения или Client ID/Secret, его карточка останется в статусе «Не настроено». Не нужно заполнять ключи всех четырёх провайдеров сразу — можно подключать их по одному.
