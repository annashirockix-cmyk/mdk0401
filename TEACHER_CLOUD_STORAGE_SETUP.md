# Подключение личных облачных хранилищ преподавателей

Поддерживаемые провайдеры: Google Drive, Яндекс Диск, OneDrive и Dropbox.

## Настройка администратором

В Apps Script откройте **Настройки проекта → Свойства скрипта** и добавьте пары свойств:

| Сервис | Client ID | Client secret |
|---|---|---|
| Google Drive | \`CLOUD_GOOGLE_CLIENT_ID\` | \`CLOUD_GOOGLE_CLIENT_SECRET\` |
| Яндекс Диск | \`CLOUD_YANDEX_CLIENT_ID\` | \`CLOUD_YANDEX_CLIENT_SECRET\` |
| OneDrive | \`CLOUD_ONEDRIVE_CLIENT_ID\` | \`CLOUD_ONEDRIVE_CLIENT_SECRET\` |
| Dropbox | \`CLOUD_DROPBOX_CLIENT_ID\` | \`CLOUD_DROPBOX_CLIENT_SECRET\` |

Для каждого приложения укажите URI возврата (redirect/callback) — точный URL веб-приложения Apps Script, заканчивающийся на \`/exec\`. Его можно получить в **Развертывание → Управление развертываниями → Веб-приложение**. Не используйте URL редактора Apps Script.

Разрешения приложений должны быть ограничены папкой приложения там, где провайдер это поддерживает:
- Google Drive: \`drive.file\`
- Яндекс Диск: \`cloud_api:disk.app_folder\`
- OneDrive: \`offline_access Files.ReadWrite.AppFolder User.Read\`
- Dropbox: \`files.content.write files.content.read account_info.read\`; тип приложения Dropbox должен быть **App Folder**.

## Важное ограничение первого этапа

Этот этап реализует OAuth-подключение, список подключённых дисков и выбор хранилища по умолчанию. Он **ещё не перенаправляет загрузку лекций в облако и не копирует существующие материалы**. Это следующий этап: загрузка файлов через серверные адаптеры, выдача студентам защищённых ссылок и резервное копирование созданного преподавателем контента.

Токены хранятся в Script Properties и не передаются браузеру или студентам. Однако редакторы самого проекта Apps Script технически могут читать свойства скрипта. Ограничьте список редакторов проекта только доверенными администраторами. Кнопка «Отключить» удаляет сохранённое порталом подключение; для полного отзыва разрешения при необходимости удалите доступ также в настройках соответствующего облачного сервиса.
