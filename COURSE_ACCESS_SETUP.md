# Подключение модульных курсов и настройка доступа

## Что добавлено

- «Материаловедение» (MAT) и «Охрана труда» (OT) помечены как отдельные подключаемые курсы.
- Для MAT и OT отключены игровые награды и достижения; XP-индикатор и игровые пункты меню скрываются.
- В редакторе преподаватель может создавать темы, лекции и тесты.
- Администратор назначает преподавателям доступ к отдельным дисциплинам.
- Учебные материалы хранятся в листе Google Sheets `CourseContent`, а назначения — в листе `Users`.

## Обязательная настройка Google Apps Script

Изменения в GitHub не обновляют автоматически уже опубликованный Google Apps Script. Чтобы редактор и права доступа работали между разными устройствами:

1. Откройте Apps Script, связанный с адресом API из файла `api.js`.
2. Замените серверный `Code.gs` содержимым одноимённого файла из этого репозитория.
3. Откройте **Настройки проекта → Свойства скрипта** и добавьте свойство:
   - Имя: `SPREADSHEET_ID`
   - Значение: ID Google-таблицы, в которой хранятся пользователи и результаты.
4. Сохраните проект и выполните **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**. Сохраните URL веб-приложения с доступом, соответствующим политике организации.
5. Убедитесь, что лист `Users` содержит учётную запись преподавателя, которую нужно сделать администратором. Если её ещё нет, сначала создайте пользователя в таблице с хешем пароля по принятой в проекте процедуре.
6. Один раз запустите из редактора Apps Script функцию:
   `promoteUserToAdmin("email-администратора")`
   Подставьте фактический email администратора и подтвердите разрешения Google.
7. Войдите в портал под этой учётной записью. В разделе **Админка → Управление доступом** отметьте дисциплины для каждого преподавателя и нажмите «Сохранить доступ».
8. Преподавателям нужно выйти и войти заново, чтобы обновить список доступных дисциплин.

## Проверка

- Войдите как администратор: доступна панель назначений.
- Назначьте преподавателю только «Материаловедение» и «Охрану труда».
- Войдите под учётной записью этого преподавателя: остальные дисциплины должны быть скрыты.
- Откройте **Редактор лекций и тестов**, создайте тестовую тему, лекцию и тест, затем проверьте их под студентом.
- Снимите отметку дисциплины в админке и повторно войдите преподавателем: доступ к предмету должен исчезнуть.

## Важные замечания

- Пока новая версия Apps Script не опубликована и свойство `SPREADSHEET_ID` не задано, изменения интерфейса уже находятся в GitHub, но серверное сохранение и управление доступом не заработают.
- Доступ преподавателей проверяется сервером, а не только скрытием кнопок в браузере.
- Для реальной эксплуатации используйте индивидуальные учётные записи; не используйте демонстрационные пароли.
