# Подключение курсов и настройка доступа

## Что поддерживает сервер

- Отдельные подключаемые курсы «Материаловедение» (MAT) и «Охрана труда» (OT).
- Назначение преподавателям индивидуального набора дисциплин.
- Роли student, teacher и admin.
- Сохранение тем, лекций и тестов в Google Sheets.
- Сохранение результатов тестирования и расписания.
- Проверка прав на сервере, а не только скрытие элементов интерфейса.
- Новые пароли хранятся в виде SHA-256-хеша с индивидуальной случайной солью. Старые учётные записи со старым форматом хеша автоматически переводятся на новый формат при успешном входе.

## Пошаговая первичная настройка

### 1. Подготовьте Google-таблицу

1. Создайте Google-таблицу, например «База учебного портала».
2. Скопируйте ID таблицы из адреса. Это часть URL между `/d/` и `/edit`.
3. Не публикуйте таблицу в открытый доступ. Доступ к ней должен быть у аккаунта Google, от имени которого выполняется Apps Script.

### 2. Откройте Apps Script

1. Откройте проект Google Apps Script, который обслуживает API портала.
2. В списке файлов откройте `Code.gs`.
3. Замените содержимое кодом из этого репозитория: [Code.gs](https://github.com/annashirockix-cmyk/mdk0401/blob/main/Code.gs).
4. Нажмите «Сохранить проект».

Если вы не знаете, какой Apps Script обслуживает сайт, откройте файл `api.js` и найдите значение `APPS_SCRIPT_URL`. Откройте соответствующий проект Apps Script из аккаунта, которому принадлежит это развертывание. Не создавайте новый проект вместо действующего, иначе сайт продолжит обращаться к старому адресу.

### 3. Укажите ID таблицы

1. В Apps Script откройте **Настройки проекта** (значок шестерёнки).
2. Найдите раздел **Свойства скрипта**.
3. Добавьте свойство:
   - **Имя:** `SPREADSHEET_ID`
   - **Значение:** ID подготовленной Google-таблицы.
4. Сохраните свойства.

### 4. Создайте структуру таблицы

1. Вернитесь в редактор кода.
2. В списке функций выберите `setupPortal`.
3. Нажмите **Выполнить**.
4. При первом запуске Google запросит разрешения. Проверьте, что открыт ваш проект, и разрешите ему работать с указанной таблицей.

В таблице должны появиться листы `Users`, `Results`, `CourseContent`, `Schedule`. Функция не удаляет существующие записи.

### 5. Создайте свою учётную запись

1. Откройте сайт портала: https://annashirockix-cmyk.github.io/mdk0401/
2. Зарегистрируйтесь со своим рабочим email и паролем не короче 8 символов.
3. Запомните email, указанный при регистрации. Пароль хранится в виде хеша и не может быть прочитан из таблицы.

### 6. Назначьте себе роль администратора

1. Вернитесь в Apps Script.
2. В списке функций выберите `promoteUserToAdmin`.
3. Нажмите **Выполнить**. Если редактор попросит аргумент, удобнее добавить временную функцию:

```javascript
function makeMyselfAdmin() {
  promoteUserToAdmin("ВАШ_EMAIL_ИЗ_РЕГИСТРАЦИИ");
}
```

4. Вместо текста в кавычках укажите тот же email, который использовали при регистрации.
5. Сохраните код и запустите `makeMyselfAdmin` один раз.
6. После успешного выполнения временную функцию можно удалить. Саму `promoteUserToAdmin` оставьте.

Функция назначает роль admin только указанной существующей учётной записи. Она не создаёт пароль и не меняет пароль.

### 7. Опубликуйте новую версию веб-приложения

1. Нажмите **Развернуть → Управление развертываниями**.
2. Выберите существующее развертывание веб-приложения и нажмите значок редактирования.
3. В поле версии выберите **Новая версия**.
4. Проверьте настройки выполнения. Обычно для такого портала выбирают выполнение от имени владельца развертывания; доступ задайте в соответствии с политикой вашей организации.
5. Нажмите **Развернуть**.

Важно: обновление файла в GitHub само по себе не обновляет уже опубликованный Apps Script. Нужно развернуть новую версию. Не создавайте новое развертывание без необходимости: файл `api.js` уже содержит URL существующего развертывания.

### 8. Проверьте вход администратора

1. Выйдите из портала.
2. Войдите снова под зарегистрированным email и паролем.
3. Откройте раздел администрирования.
4. Убедитесь, что отображается управление доступом преподавателей.

### 9. Назначьте дисциплины преподавателям

1. Преподаватель должен предварительно зарегистрироваться на сайте.
2. В таблице `Users` найдите его строку и в колонке `Role` установите `teacher` (если роль ещё не назначена).
3. Войдите под администратором и откройте **Админка → Управление доступом**.
4. Отметьте дисциплины, которые должен вести преподаватель, и сохраните изменения.
5. Попросите преподавателя выйти и войти заново, чтобы обновить список доступных дисциплин.

## Проверка редактора

Под учётной записью преподавателя с назначенной дисциплиной откройте редактор, создайте тему, лекцию и тест. Перезагрузите страницу и проверьте, что материалы сохранились. Преподаватель без назначенной дисциплины не должен иметь возможности изменять её материалы.

## Важные замечания

- Не отправляйте никому пароль, токен сессии или полный доступ к Google-таблице.
- Если сайт возвращает ошибку о сессии, выйдите и войдите снова.
- Если сервер возвращает HTML вместо JSON, проверьте, что обновили именно существующее развертывание Apps Script и что доступ к веб-приложению разрешён нужным пользователям.
- Если появляется ошибка о `SPREADSHEET_ID`, проверьте имя свойства и ID таблицы.
- Скрипт не создаёт демонстрационные логины и пароли.
