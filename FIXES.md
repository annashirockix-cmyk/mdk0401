## Как залить на GitHub Pages

**Вариант А (рекомендуется)** — только исправленные файлы:
1. Возьмите из архива `data-mastercam.js` и `style.css`
2. Замените ими одноимённые файлы в корне репозитория
3. Commit + push
4. На сайте: «Сбросить кэш» или Ctrl+F5

**Вариант Б** — полный код из архива:
1. Распакуйте архив поверх репозитория
2. **Не удаляйте** папки, которых нет в архиве:
   - `attachments/` (видео, ИОТ, паспорта)
   - `presentations/`
   - `passport/`, `pdf/`, `metodichka/`, `ohranatruda/` и т.п.
3. Commit + push
4. Сброс кэша на сайте
